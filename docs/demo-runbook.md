# 시연 런북

이 문서는 기말 발표에서 보여 줄 두 시나리오의 진행 순서를 정한다. 두 시나리오 모두 구매자가 보험을 들고, 투자자가 지분을 입찰하고, 발표자가 오라클 화면에서 판정과 시간 이동을 누른다.

## 준비

스택을 켜고 화면 세 장을 연다. 블록은 12초마다 하나씩 쌓이므로 트랜잭션마다 최대 12초를 기다린다.

```bash
LAN=1 ./script/local-up.sh                     # 폰 참여가 있으면 LAN=1, 발표 동안만 켠다
python3 -m http.server 8099 --bind 0.0.0.0     # 레포 루트에서
```

```text
구매자   http://<노트북 주소>:8099/ui/buyer.html
투자자   http://<노트북 주소>:8099/ui/investor.html
발표자   http://127.0.0.1:8099/ui/oracle.html     오라클 API는 노트북에서만 열린다
```

## 시나리오 1: 일정이 무사함 → 투자자가 보험료를 받음

1. 구매자 화면에서 "예약하기 (Mock)"로 KTX 예약 NFT를 받는다.
2. 예약 카드의 "보험 들기"에서 보험료 · 최소 보장금액 · 모집 시간을 정해 가입한다.
3. 투자자 화면(alice · bob)에서 지분 수와 지분당 보장금액을 입찰한다.
4. 오라클 화면에서 "정상"을 누르고 "모집 마감으로 이동", "판정 시작으로 이동"을 차례로 누른다.
5. 오라클 서버가 판정을 보내면 보험이 "만료"가 된다. 투자자 화면에서 "청구하기" → "출금하기"로 예치금과 보험료 몫을 받는다.

## 시나리오 2: 일정이 틀어짐 → 구매자가 보장금을 받음

1. 시나리오 1의 1~3을 숙소 예약으로 반복한다.
2. 오라클 화면에서 "지연"을 누르고 "모집 마감으로 이동", "판정 시작으로 이동"을 누른다.
3. 보험이 "지급"이 되면 구매자 화면의 "출금하기"로 보장금을 받는다.

## 보조 장면

```text
유찰       입찰 없이 모집 마감으로 이동 → 구매자 화면 "보험료 돌려받기"
부분 체결  지분 100개보다 적게 입찰 → 마감 뒤 "보험료 돌려받기"로 남은 보험료를 받음
무효       판정 없이 "판정 종료로 이동" → 투자자 "청구하기"가 무효로 확정하고 예치금을 돌려받음
```
