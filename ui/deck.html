체인에 바로 묻기 (JSON-RPC)

노드에 HTTP POST 한 번이면 됩니다. 보험 수 · 상태 · 현재 가격 · 조건 트리가 모두 view 함수와 이벤트 로그로 열려 있습니다.

# eth_call · 보험 #4의 현재 보장금액 { "method": "eth_call", "params": [{ "to": "0xCf7E…0Fc9", "data": "0x1f57948f…0004" }, "latest"], … } → { "result": "0x…39bd0d4e5c0000" } = 0.26 ETH # eth_getLogs · 체결 이벤트 전부 { "method": "eth_getLogs", "params": [{ "address": "0xCf7E…0Fc9", "topics": ["0xa64d…ac9c"], … }] }
